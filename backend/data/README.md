# Data

## ⚠️ Real copyrighted policy PDFs -- gitignored, never committed

`data/policies/*.pdf` are **real specimen/sample insurance policy documents**, publicly
published by RBC Insurance for consumer reference, downloaded directly from
rbcinsurance.com. They are © RBC Life Insurance Company, used here for private
development/testing only, and are **listed in `.gitignore` (`backend/data/policies/*.pdf`)
so they never enter git history at all** -- not even in a private repo.

**A fresh clone of this repo will not have these files.** Fetch them with:
```bash
python scripts/download_real_policies.py
python ingest.py   # rebuild the ChromaDB collection afterwards
```

Because these files are real copyrighted documents, still **do not make this
repository public** even though git itself no longer tracks them -- someone
who has already cloned it, or who runs the download script, will have local
copies. If this project needs to go public, remove the download script's
purpose entirely and switch back to the synthetic fallback (see
`policies_mock_backup/` below).

| File | Product | Source |
|---|---|---|
| `rbc_term_life.pdf` | Term life insurance | https://www.rbcinsurance.com/samplepolicy/pdf/your-term-sample-policy.pdf |
| `your-term-rider.pdf` | Riders for the above | https://www.rbcinsurance.com/samplepolicy/pdf/your-term-rider.pdf |
| `t100-policy.pdf` | Term 100 (permanent) life insurance | https://www.rbcinsurance.com/samplepolicy/pdf/t100-policy.pdf |
| `rbc-ul-policy.pdf` | Universal life insurance | https://www.rbcinsurance.com/samplepolicy/pdf/rbc-ul-policy.pdf |
| `rbc-ul-policy-bonus.pdf` | Universal life insurance (bonus interest) | https://www.rbcinsurance.com/samplepolicy/pdf/rbc-ul-policy-bonus.pdf |
| `ul-rider-package.pdf` | Riders for universal life | https://www.rbcinsurance.com/samplepolicy/pdf/ul-rider-package.pdf |
| `rbc_critical_illness.pdf` | Critical illness insurance | https://www.rbcinsurance.com/health-insurance/pdf/critical-illness-insurance-plan-sample-policy.pdf |
| `rbc_disability_income.pdf` | Disability income insurance (includes an AD&D rider section) | https://assets.rbcinsurance.com/m/ab8e41544b7cee55/original/The-Fundamental-Series-Disability-Income-Protection.pdf |

All are marked "Specimen" by the issuer, meaning they are published copies for
public review and do not represent any real policyholder's contract.

## `policies_mock_backup/`
The original fully-synthetic HTML policy templates (written from scratch, not
copied from any real insurer) that this project used before switching to the
real specimen PDFs above. Kept as a drop-in fallback: if this project needs to
go public, delete `policies/*.pdf` and move these back into `policies/`
(`ingest.py` would need its policy-parsing function pointed at `.html` again,
see git history for the previous version of `ingest.py`).

## `underwriting_criteria.xlsx`
Fully synthetic — not derived from any real insurer's proprietary underwriting
formula (those are trade secrets and not publicly available). Generated by
`scripts/generate_underwriting_excel.py`. `risk_calculator` (Phase 2) reads
this file directly at runtime rather than hardcoding the formula.

## `applicants.json`
26 synthetic applicant cases (18 randomly generated + 8 explicitly authored
edge cases covering high risk, borderline band values, and missing required
fields). Generated by `scripts/generate_applicants.py` (fixed random seed).
No real applicant, customer, or health data is used anywhere in this project.

Regenerate the synthetic files with:
```bash
python scripts/generate_underwriting_excel.py
python scripts/generate_applicants.py
```
